道場 実験室 理論帳

目次

ひとことで

機械学習は、データから「入力 → 出力」の規則をコンピューターに見つけさせる方法です。正解つきで学ぶ・正解なしで構造を探す・報酬で行動を学ぶ、の3つに大きく分かれます。

しくみ

人が規則を1つずつ書くかわりに、たくさんの例から規則を学ばせるのが機械学習です。学び方は大きく3種類あります。

  • 教師あり学習: 入力と正解(ラベル)の組から、入力から正解を当てる規則を学ぶ。当てる値が気温や価格のような連続した数なら回帰、「猫か犬か」のように決まった種類(クラス)のどれかなら分類。
  • 教師なし学習: 正解なしで、データの中の構造を見つける。似たものどうしをまとめるクラスタリング(k-means 法など)が代表例。
  • 強化学習: エージェントが環境の中で行動し、得られる報酬の合計が大きくなるような行動の選び方(方策)を学ぶ。1つ1つの行動に正解は与えられない。

予測の手がかりとしてモデルに入れる値を特徴量、当てたい値をラベル(目的変数)といいます。家の価格の予測なら、床面積・駅からの距離・築年数が特徴量、価格がラベルです。もっとも単純な線形モデルは、特徴量に重みをかけて足し、最後にバイアスを足します。

y=w1x1 + w2x2 + … + b

重みやバイアスのように学習でデータから決まる値をパラメータ、学習率・エポック数・層の数のように学習の前に人が決める値をハイパーパラメータといいます。

機械学習の本当の目標は、学習に使っていない新しいデータでもうまく予測できること(汎化)です。そこで、データを役割の違う3つに分けます。

データ使いみち
訓練データ重み(パラメータ)を学習する
検証データハイパーパラメータやモデルを比べて選ぶ
テストデータ学習と調整が終わったあと、最後に性能を見積もる

例で確かめる

例1: 線形モデルの予測

y = 3x1 − 2x2 + 4 に、x1 = 2、x2 = 1 を入れる。

  1. 重みをかける: 3 × 2 = 6、−2 × 1 = −2。
  2. 足してバイアスを足す: 6 − 2 + 4 = 8。

例2: データの分割

2000 件を 訓練 : 検証 : テスト = 80 : 10 : 10 に分ける。

  1. 訓練: 2000 × 0.8 = 1600 件。
  2. 検証: 2000 × 0.1 = 200 件。テストも同じく 200 件。

例3: でたらめな答えの正解率(比べる基準)

4種類のクラスが同じ数ずつあるとき、4つから等しい確率で選ぶと、当たる確率は 1 ÷ 4 = 25%。作ったモデルの正解率は、このような基準より高いかどうかで見ます。

よくある誤解・注意

  • テストデータで調整しない。テストの成績を見ながら設定を変えると、テストデータに合わせこんでしまい、性能を高く見積もりすぎます。調整には検証データを使います。
  • データリークに気をつける。テストデータの一部が訓練データにまざるなど、評価用の情報が学習に入りこむと、モデルが「答えを見た」状態になり、本当の性能より良く見えます。
  • 訓練データでの誤差が 0 でも、よいモデルとは限らない。大事なのは新しいデータでの性能(汎化)です。訓練データにだけ合いすぎた状態を過学習といいます。

ひとことで

線形回帰は、データに直線 y = wx + b をあてはめる方法です。予測と実測のずれを損失(MSE など)で1つの数にし、それが最小になる傾きと切片を選びます。

しくみ

直線 y = wx + b の w(傾き)は「x が 1 増えたときの y の増え方」、b(切片)は「x = 0 のときの値」です。特徴量が2つ以上あっても、重みをかけて足し、切片を足すことは同じです(重回帰)。

実測値と予測値の差を残差といいます。向きに注意してください。

残差=実測値 y − 予測値 ŷ

残差が正なら、モデルは実際より小さく予測しています。モデルの悪さを1つの数にまとめたものが損失関数で、学習とは損失が小さくなるようにパラメータを調整することです。回帰でよく使う損失・指標は次のとおりです(n はデータの件数)。

MSE=(残差の2乗の和)n
MAE=(残差の絶対値の和)n
RMSE=√MSE

MSE(平均二乗誤差)は誤差を2乗するので、大きな誤差ほど強く効きます。MAE(平均絶対誤差)は外れ値の影響を受けにくい指標です。RMSE は誤差と同じ単位にもどるので、「だいたい何ずれるか」をつかみやすくなります。

残差の2乗の和が最小になるように傾きと切片を決めるのが最小二乗法です。線形回帰では、最小値を与える係数を式で直接求められます(x、y は平均)。

w = Σ(x − x)(y − y)Σ(x − x)2b = y − wx

当てはまりのよさは決定係数 R2 でも表します。「いつも平均で予測する」ときと比べて、誤差をどれだけ減らせたかの割合です。

R2=1 − 残差の2乗和平均からのずれの2乗和

例で確かめる

例1: 図の直線を最小二乗法で求め、MSE と R2 を出す

  1. 平均: x = 2.5、y = (2 + 5 + 4 + 7) ÷ 4 = 4.5。
  2. Σ(x − x)(y − y) = (−1.5)(−2.5) + (−0.5)(0.5) + (0.5)(−0.5) + (1.5)(2.5) = 7、Σ(x − x)2 = 5。
  3. w = 7 ÷ 5 = 1.4、b = 4.5 − 1.4 × 2.5 = 1。直線は ŷ = 1.4x + 1。
  4. 予測は 2.4、3.8、5.2、6.6。残差は −0.4、1.2、−1.2、0.4。2乗の和は 0.16 + 1.44 + 1.44 + 0.16 = 3.2。
  5. MSE = 3.2 ÷ 4 = 0.8。RMSE = √0.8 ≒ 0.89。
  6. 平均からのずれの2乗和 = 2.52 + 0.52 + 0.52 + 2.52 = 13。R2 = 1 − 3.2 ÷ 13 ≒ 0.75。

例2: 外れ値に強いのはどちらか

4件の誤差が「1, 1, 1, 1」のモデル A と、「0, 0, 0, 4」のモデル B を比べる。

  1. MAE: A は 4 ÷ 4 = 1、B も 4 ÷ 4 = 1 で同じ。
  2. MSE: A は 4 ÷ 4 = 1、B は 16 ÷ 4 = 4。1件の大きな外れが、MSE では4倍の差になる。

例3: 定数で予測するときの最良の値

どの入力にも同じ値 c を予測するとき、データ 1、2、9 に対して MSE を最小にするのは平均 (1 + 2 + 9) ÷ 3 = 4、MAE を最小にするのは中央値 2 です。

よくある誤解・注意

  • 残差の向き。残差は「実測 − 予測」です。逆にすると符号が反対になります(2乗する MSE の値は変わりません)。
  • 残差に形が見えたら要注意。直線でうまく表せていれば、残差は 0 のまわりに規則なく散らばります。残差を x に対して並べて U 字形などが見えるなら、関係が直線ではなく曲線的です。
  • 傾きは「関係」を表すだけ。「勉強時間が1時間増えると予測点数が3点上がる」は予測の読み方で、勉強すれば必ずそうなるという因果を示すものではありません。
  • R2 の範囲。訓練データに最小二乗で合わせた直線(切片あり)では 0〜1 になりますが、別のデータで測ると、平均で予測するより悪ければ負にもなります。

ひとことで

勾配降下法は、損失の坂の傾き(勾配)を調べ、その逆向きに少しずつパラメータを動かして、損失の谷底を探す方法です。1歩の大きさは学習率 η で決まります。

しくみ

損失 L を重み w で微分した値(勾配)は、w を増やしたときに損失が増える向きと急さを表します。損失を減らしたいので、勾配の逆向きに進みます。

w←w − η × (L の w による微分)

坂が急なほど1歩が大きく、谷底(勾配 0)に近づくほど1歩が小さくなります。パラメータが複数あるときは、それぞれの微分(偏微分)の分だけ、パラメータごとに動かします。

学習率 η の決め方が大切です。損失 L = w2 で考えると、微分は 2w なので、1歩は次のように書けます。

w←w − η × 2w = (1 − 2η)w

毎回 (1 − 2η) 倍になるので、|1 − 2η| < 1、つまり 0 < η < 1 のときに 0 へ収束します。

η1歩でかかる倍率w = 1 からの動きようす
0.10.81 → 0.8 → 0.64まっすぐ近づく(ゆっくり)
0.501 → 01歩で最小に着く
0.75−0.51 → −0.5 → 0.25谷をはさんで行き来しながら近づく
1−11 → −1 → 1同じ2点を行き来し続ける
1.25−1.51 → −1.5 → 2.25離れていく(発散)

損失が (w − 3)2 のように谷底がずれていても、「谷底からの距離」が毎回 (1 − 2η) 倍になるので、同じことがいえます。

実際の学習では、データを小分けにしたミニバッチごとに勾配を計算して更新します(確率的勾配降下法、SGD)。訓練データ全体を1回ずつ使い切ることを1エポックといい、1エポックの更新回数は「データ数 ÷ ミニバッチの大きさ」です(割り切れる場合)。一部のデータで勾配を見積もるので1回の計算は軽いかわりに、勾配に「ばらつき」がまざります。

勾配降下法を改良した方法もよく使われます。モメンタムは、これまでの勾配を「速度」のようにためて使い、同じ向きには加速し、行き来する振動は打ち消し合っておさえます。Adam は、勾配の移動平均(モメンタムに近いもの)と、勾配の2乗の移動平均を組み合わせ、パラメータごとに1歩の大きさを調整します。勾配の大きさで割るので、勾配が大きいパラメータでも飛びすぎず、1歩はおよそ η 程度にそろいます。勾配の向きが行き来してばらつくパラメータでは、分子の平均が打ち消し合って小さくなり、1歩も小さくなります。

Adam(おおまかな形)w ← w − η × (勾配の移動平均)√(勾配の2乗の移動平均) + ε

実際には、最初のうちの値のかたよりを直す補正も入ります。ε は 0 で割らないための小さな数です。

例で確かめる

例1: L = (w − 3)2、w = 0、η = 0.25(上の図)

  1. 微分は 2(w − 3)。w = 0 では 2 × (0 − 3) = −6(負なので、w を増やす向きが下り坂)。
  2. w ← 0 − 0.25 × (−6) = 1.5。
  3. 次の勾配は 2 × (1.5 − 3) = −3。w ← 1.5 − 0.25 × (−3) = 2.25。以後 2.625、2.8125 … と 3 に近づく。

例2: パラメータが2つ

L = 2w12 + w22、(w1, w2) = (1, 2)、学習率 0.1。

  1. 勾配は (4w1, 2w2) = (4, 4)。
  2. (1 − 0.1 × 4, 2 − 0.1 × 4) = (0.6, 1.6)。

例3: データ1件で重みを更新する

x = 3、y = 4、モデル ŷ = wx、損失 L = (ŷ − y)2、w = 2、学習率 0.01。

  1. 予測 ŷ = 2 × 3 = 6。
  2. 勾配 = 2(ŷ − y) × x = 2 × (6 − 4) × 3 = 12。
  3. w ← 2 − 0.01 × 12 = 1.88。予測が大きすぎたので w が小さくなった。

例4: 1エポックの更新回数

訓練データ 6000 件、ミニバッチ 100 件なら、6000 ÷ 100 = 60 回。10 エポック学習すると 600 回更新します。

よくある誤解・注意

  • 符号はマイナス。勾配は損失が増える向きを指すので、「w − η × 勾配」です。プラスにすると坂を登ります。
  • 学習率は大きければ速い、とは限らない。大きすぎると谷を飛びこえて振動したり発散したりします。小さすぎると、正しい向きでも1歩がわずかで、収束が遅くなります。
  • 止まった場所が一番低いとは限らない。谷が複数あると、浅い谷の底(局所解)で止まることがあります。そこでは勾配が 0 なので、それ以上動きません。どの谷に着くかは初期値などで変わります。

ひとことで

分類では、モデルが「陽性らしさ」を確率やスコアで出し、しきい値で陽性・陰性に分けます。結果は混同行列にまとめ、正解率だけでなく適合率・再現率・F1 で評価します。

しくみ

2つのクラス(陽性・陰性)に分ける代表的な方法がロジスティック回帰です。まず線形モデルで z = wx + b を計算し、それをシグモイド関数に通して「陽性の確率」にします。

σ(z)=11 + e−z

σ(z) は z が大きいと 1 に、小さいと 0 に近づきますが、どちらにも届きません(値は 0 より大きく 1 より小さい)。σ(0) = 0.5 で、点 (0, 0.5) について対称な形なので σ(−z) = 1 − σ(z) が成り立ちます。σ(z) が 0.5 より大きいのは z > 0 のときなので、z = 0 になるところが「確率 50%」の境目です。

学習の損失には交差エントロピーを使います。正解のクラスにモデルがつけた確率を p とすると、損失は −ln p(ln は自然対数)。2クラスで正解が陽性なら −ln(陽性の確率)、陰性なら −ln(1 − 陽性の確率)です。p が 1 に近いほど損失は 0 に近く、正解に低い確率をつける(自信をもって間違える)ほど、上限なく大きくなります。

正解のクラスの確率 p損失 −ln p
0.9≒ 0.11
0.5≒ 0.69
0.1≒ 2.30
0.01≒ 4.61

判定は「陽性の確率(スコア)がしきい値以上なら陽性」とします。結果を数えた表が混同行列で、行が実際、列が予測です。TP・FN・FP・TN の頭の T/F は予測が当たったか外れたか、P/N は予測の側の答えを表します。

  • 正解率 = (TP + TN) ÷ 全体。
  • 適合率 = TP ÷ (TP + FP)。陽性と予測したもののうち、本当に陽性だった割合(誤検出 FP の少なさ)。
  • 再現率 = TP ÷ (TP + FN)。実際に陽性のもののうち、陽性と見つけられた割合(見逃し FN の少なさ)。
  • F1 スコア = 2 × 適合率 × 再現率 ÷ (適合率 + 再現率) = 2TP ÷ (2TP + FP + FN)。適合率と再現率の調和平均。

しきい値を上げると、陽性と判定するデータは減るか同じなので、TP も減るか同じで、再現率は下がるか変わりません。かわりに誤検出(FP)が減りやすく、適合率は上がることが多くなります(必ずではありません)。しきい値を下げると逆です。どこに置くかは目的しだいです。

例で確かめる

例1: 混同行列から4つの指標を出す

  1. 正解率 = (45 + 35) ÷ 100 = 0.80。
  2. 適合率 = 45 ÷ (45 + 5) = 0.90。
  3. 再現率 = 45 ÷ (45 + 15) = 0.75。
  4. F1 = 2 × 45 ÷ (2 × 45 + 5 + 15) = 90 ÷ 110 ≒ 0.82。

例2: ロジスティック回帰の境目

z = 0.5x − 3、σ(z) ≥ 0.5 なら陽性と判定するとき。

  1. σ(z) ≥ 0.5 になるのは z ≥ 0 のとき(σ(0) = 0.5)。
  2. 0.5x − 3 ≥ 0 より x ≥ 6 で陽性と判定する(x = 6 では陽性の確率がちょうど 50%)。

例3: 不均衡なデータ

1000 件のうち陽性が 20 件(2%)のデータで、すべて「陰性」と答えるモデルは、陰性 980 件がすべて当たるので正解率 98%。でも陽性を1件も見つけていないので、再現率は 0% です。

よくある誤解・注意

  • 正解率が高い = よいモデル、とは限らない。陽性がとても少ない不均衡データでは、全部「陰性」でも正解率が高くなります。再現率や適合率もあわせて見ます。
  • FP と FN を取りちがえない。FP(偽陽性)は「実際は陰性なのに陽性と予測」、FN(偽陰性)は「実際は陽性なのに陰性と予測(見逃し)」。
  • 何を重視するかは目的しだい。病気の検査で見逃し(FN)を減らしたいなら再現率、迷惑メールの判定で大事なメールを捨てたくない(FP を減らしたい)なら適合率を重視します。
  • −1〜1 になるのは tanh。シグモイドの値は 0〜1 の間(両端はふくまない)です。

再現率
TP ÷ (TP + FN)。陽性の見つけもらしの少なさ。
F1 スコア
適合率と再現率の調和平均。
不均衡データ
クラスの数が大きくかたよったデータ。
ひとことで

過学習は、訓練データの細かいくせ(ノイズ)まで覚えてしまい、新しいデータで外れる状態です。正則化・ドロップアウト・早期終了・データ拡張などで抑え、検証データで確かめます。

しくみ

モデルの状態は、訓練データと検証データの誤差を並べるとわかります。

状態訓練誤差検証誤差主な原因
未学習大きい大きいモデルが単純すぎる
ちょうどよい小さい小さい(訓練との差も小さい)—
過学習とても小さい大きい(差が大きい)モデルが複雑すぎる・データが少ない

この2つの失敗はバイアスとバリアンスで説明できます。バイアスは、モデルが単純すぎるために生じる系統的なずれ(未学習側)。バリアンスは、訓練データが少し変わるだけで予測が大きく変わる、ばらつき(過学習側)です。二乗誤差の期待値は次のように分けられます。

二乗誤差の期待値=バイアス2 + バリアンス + 減らせないノイズ

モデルを複雑にするとバイアスは減りやすく、バリアンスは増えやすくなります。過学習をおさえる主な方法は次のとおりです。

  • 正則化: 損失に「重みの大きさ」の罰を足す。係数 λ が大きいほど、重みを小さくする力が強い。
    L2: λ × (w12 + w22 + …)L1: λ × (|w1| + |w2| + …)
    L2 正則化(Ridge)は重みを全体に小さくしますが、ちょうど 0 にはなりにくい。L1 正則化(Lasso)はいくつかの重みがちょうど 0 になりやすく(スパース)、使う特徴量をしぼりこめます。
  • ドロップアウト: 訓練中に、ランダムに選んだニューロンの出力を 0 にして学習する。特定のニューロンにたよりすぎるのを防ぐ。推論(予測)のときはふつう全ニューロンを使い、出力の大きさが訓練時とそろうように調整する。
  • 早期終了: エポックごとに検証誤差を見て、下がらなくなったところで学習を止め、検証誤差が最小のときのモデルを使う。
  • データ拡張: 意味(正解ラベル)が変わらない範囲で画像を少し回す・ずらす・明るさを変えるなどして、訓練データを増やす。

データが少ないときの評価には交差検証を使います。k 分割交差検証では、データを k 個に分け、1つを検証、残りを訓練に使う学習を、検証に使う1つを入れかえながら k 回行い、成績の平均で評価します。

例1: 正則化の項

重み (1, −2, 2)、λ = 0.5 のとき。

  1. L2: 12 + (−2)2 + 22 = 9。0.5 × 9 = 4.5。
  2. L1: |1| + |−2| + |2| = 5。0.5 × 5 = 2.5。

例2: 早期終了で選ぶエポック

例3: ドロップアウトと交差検証の数

  1. 200 個のニューロンに割合 0.5 のドロップアウト: 止まるのは平均 200 × 0.5 = 100 個、使われるのは平均 100 個。
  2. 1000 件で 10 分割交差検証: 1回の学習は 検証 100 件・訓練 900 件。これを 10 回行う。

よくある誤解・注意

  • 訓練誤差だけで良し悪しを決めない。多項式の次数を上げると、高い次数は低い次数の式をふくむので訓練誤差は増えません。でもテスト誤差は、ある次数から上がりはじめます。
  • 正則化は強ければよい、ではない。λ を大きくしすぎると、必要な重みまで抑えられて未学習になります。
  • データ拡張は意味を変えない範囲で。手書き数字を180度回すと「6」が「9」のように見え、正解ラベルと合わなくなります。
  • ドロップアウトは訓練中だけ。推論のたびにランダムにニューロンを消すわけではありません。

ひとことで

ニューラルネットワークは、「重み付き和 → 活性化関数」をするニューロンを層にして重ねたモデルです。誤差逆伝播法で全部の重みの勾配を求め、勾配降下法で学習します。

しくみ

1つのニューロンは、入力に重みをかけて足し、バイアスを足した重み付き和 z を、活性化関数 φ に通して出力します。

z = w1x1 + w2x2 + … + b出力 = φ(z)

重みは入力の効き方を、バイアスは出力が切りかわる位置(しきい値)を調整します。たとえば z = wx + b が 0 になるのは x = −b ÷ w なので、b を変えると境目が動きます。

いちばん古い形のパーセプトロンは、活性化関数にステップ関数(z > 0 なら 1、そうでなければ 0)を使います。重みとバイアスを選ぶと AND や OR を表せますが、1層(直線1本で分ける)では XOR は表せません。(0,1)・(1,0) と (0,0)・(1,1) を直線1本では分けられないからです。層を重ねる(多層パーセプトロン)と表せます。

層の間に活性化関数が必要なのは、それが非線形だからです。線形変換は何回重ねても、まとめると1つの線形変換になってしまいます。間に非線形な関数をはさむことで、曲がった複雑な関係を表せるようになります。

隣の層のすべてのニューロンとつながる層を全結合層といいます。パラメータの数は次のとおりです。

全結合層のパラメータ数=入力数 × 出力数(重み) + 出力数(バイアス)

学習では、損失を各重みで微分した値(勾配)が必要です。誤差逆伝播法(バックプロパゲーション)は、出力側から入力側へ、連鎖律(合成関数の微分)で微分をかけ合わせて、すべての重みの勾配を効率よく求めます。求めた勾配で、勾配降下法によって重みを更新します。

L の w による微分=(L の z による微分) × (z の w による微分)

層が深いと、逆伝播で微分を何度もかけ合わせるうちに勾配がとても小さくなり、入力に近い層が学習しにくくなることがあります(勾配消失)。シグモイドの微分 σ(z)(1 − σ(z)) は最大でも 0.25(z = 0 のとき)なので起こりやすく、ReLU は正の範囲で微分が 1 なので起こりにくくなります。ほかに、層を飛びこす経路をつくる残差接続、重みの初期値の工夫、バッチ正規化なども使われます。

例で確かめる

例1: パーセプトロンで OR と AND(z > 0 なら 1)

重み (1, 1) のまま、バイアスだけを変える。

(x1, x2)b = −0.5 の z出力b = −1.5 の z出力
(0, 0)−0.50−1.50
(1, 0)0.51−0.50
(0, 1)0.51−0.50
(1, 1)1.510.51

b = −0.5 は OR(どちらかが 1 なら 1)、b = −1.5 は AND(両方 1 のときだけ 1)。XOR は、OR の出力と NAND(重み (−1, −1)、b = 1.5)の出力を AND に入れる2層で作れる。

例2: 小さなネットワークの順伝播(中間層は ReLU、出力層は活性化なし)

入力 (x1, x2) = (2, 1)。

  1. h1 = ReLU(1 × 2 + 1 × 1 − 2) = ReLU(1) = 1。
  2. h2 = ReLU(−1 × 2 + 1 × 1) = ReLU(−1) = 0(負は 0)。
  3. y = 3 × h1 − 2 × h2 + 1 = 3 − 0 + 1 = 4。

例3: 連鎖律で勾配を求める

z = wx + b、L = (z − t)2、x = 3、w = 0.5、b = 1、正解 t = 4。

  1. z = 0.5 × 3 + 1 = 2.5。
  2. L の z による微分 = 2(z − t) = 2 × (2.5 − 4) = −3。
  3. z の w による微分は x = 3。連鎖律で −3 × 3 = −9。(b による微分は −3 × 1 = −3)

例4: パラメータの数

入力 10 → 中間層 5 → 出力 3: (10 × 5 + 5) + (5 × 3 + 3) = 55 + 18 = 73。バイアスを数え忘れると 65 になる。

よくある誤解・注意

  • 層を増やすだけでは表現力は増えない。活性化関数がない(線形のまま)なら、何層重ねても1層の線形変換と同じです。
  • パラメータ数にはバイアスも入る。出力1つにバイアス1個です。
  • 値の範囲を取りちがえない。シグモイドは 0〜1、tanh は −1〜1、ステップは 0 か 1、ReLU は 0 以上で上限なし。
  • 誤差逆伝播法は「勾配の求め方」。重みを動かすのは、その勾配を使う勾配降下法です。

ひとことで

CNN は小さなフィルタを画像全体で使い回して模様を見つけ、RNN は系列を前から順に処理し、Transformer は自己注意で系列のすべての位置どうしを一度に見比べます。

しくみ: CNN(畳み込みニューラルネットワーク)

畳み込みは、小さなフィルタ(例: 3×3)を画像の上で少しずつずらしながら、重なった位置どうしをかけて足し、1つの値を出す操作です。フィルタの重みは画像のすべての位置で共通(重み共有)なので、全結合層よりずっと少ないパラメータで済み、同じ模様がどこにあっても見つけられます。

出力の大きさは、入力の1辺 N、フィルタの1辺 F、パディング(まわりに足す 0 の幅)P、ストライド(ずらす幅)S で決まります。

出力の1辺=(N − F + 2P) ÷ S + 1

割り切れないとき、多くの実装では小数点以下を切り捨てます。

畳み込み層のパラメータ数は、フィルタ1個の重み(F × F × 入力チャンネル数)× フィルタの数(出力チャンネル数)+ バイアス(フィルタ1個に1個)です。畳み込みのあとには、領域ごとに最大値を残す最大値プーリング(平均をとるなら平均値プーリング)で、特徴マップを小さくすることがよくあります。プーリングには学習するパラメータがありません。

しくみ: RNN と LSTM

RNN(再帰型ニューラルネットワーク)は、文章や時系列のような順番のあるデータを前から1つずつ処理し、前の時刻の隠れ状態を次の時刻に渡します。長い系列では、遠い過去の情報が勾配消失で伝わりにくいことがあります。LSTM は、情報の通り道であるセル状態と、そこに残す情報・捨てる情報を調節するゲート(忘却・入力・出力)を持ち、長い依存関係を学びやすくしたものです。

しくみ: Transformer と自己注意

Transformer の中心は自己注意(self-attention)です。各トークンからクエリ q・キー k・バリュー v の3つのベクトルを作り、次の手順で情報を集めます。

  1. あるトークンのクエリと、系列の各トークンのキーの内積をとり、√d(d はベクトルの次元)で割って「関連の強さ」のスコアにする。
  2. スコアをソフトマックスで重み(合計 1)にする。
  3. 各トークンのバリューを、その重みで重み付き平均する。これが出力。
スコア=q と k の内積√d

√d で割るのは、次元が大きいと内積が大きくなりやすく、ソフトマックスが1つに極端に集中するのを防ぐためです。

自己注意では、離れた位置のトークンどうしも1回で直接参照できます。そのかわり、長さ n の系列では n × n 組の重みを計算するので、長さが2倍になると4倍になります。また、自己注意はトークンの並びを入れかえても同じように計算されるので、並び順を区別するために位置エンコーディング(位置を表すベクトルを埋め込みに足す、などの方法)で位置の情報を加えます。

トークンは最初に埋め込みで、単語ごとに1本のベクトルに変えます。埋め込み表のパラメータ数は 語彙数 × 次元 です。意味の近い語は近い向きのベクトルになるように学習され、向きの近さはコサイン類似度(内積 ÷ 長さの積。−1〜1)で測ります。

例で確かめる

例1: 畳み込みの出力の大きさ(入力 64×64)

  1. 3×3、パディング 0、ストライド 1: (64 − 3 + 0) ÷ 1 + 1 = 62。
  2. 5×5、パディング 2、ストライド 1: (64 − 5 + 4) ÷ 1 + 1 = 64(大きさが変わらない)。
  3. 4×4、パディング 1、ストライド 2: (64 − 4 + 2) ÷ 2 + 1 = 31 + 1 = 32(およそ半分)。

例2: 畳み込みと最大値プーリングを計算する

  1. 左上: 左の列 (2 + 0 + 1) × 1 + 中の列 × 0 + 右の列 (0 + 3 + 2) × (−1) = 3 − 5 = −2。
  2. 1つ右へずらして同じように計算すると −1。出力は (4 − 3) ÷ 1 + 1 = 2 で 2×2。
  3. 最大値プーリング: 2×2 の領域 [1, 3; 4, 2] なら最大の 4 を残す(平均値プーリングなら 2.5)。

例3: 自己注意の重み(上の図の数値)

クエリ q = (1, 2)、キー「猫」(1, 0)・「が」(0, 1)・「鳴いた」(1, 1)、d = 2。

  1. 内積は 1、2、3。√2 ≒ 1.414 で割ると、スコアは ≒ 0.71、1.41、2.12。
  2. ソフトマックスで重みにすると ≒ 0.14、0.28、0.58(合計 1)。
  3. バリューが「猫」(10, 0)・「が」(0, 10)・「鳴いた」(5, 5) なら、出力 ≒ 0.14 × (10, 0) + 0.28 × (0, 10) + 0.58 × (5, 5) ≒ (4.3, 5.7)。

例4: パラメータ数・計算量・類似度

  1. 入力 16 チャンネルに 3×3 のフィルタを 32 個: 3 × 3 × 16 × 32 + 32 = 4640。
  2. 系列の長さ 1000 → 2000: 注意の重みは 1,000,000 → 4,000,000 で 4倍。
  3. 語彙 30000、次元 512 の埋め込み表: 30000 × 512 = 15,360,000。
  4. (1, 0) と (1, 1) のコサイン類似度: 1 ÷ (1 × √2) ≒ 0.71。(1, 2) と (−2, 1) は内積 0 で直角なので 0。

よくある誤解・注意

  • パディングは2倍する。出力の式は 2P(両側に足すため)。
  • バイアスはフィルタ1個に1個。チャンネルごとではありません。
  • CNN の「畳み込み」は、フィルタを反転しない。数学の畳み込みとは少し違い、正確には相互相関という計算ですが、慣習で畳み込みと呼びます。
  • 自己注意だけでは順番がわからない。そのために位置エンコーディングがあります。
  • コサイン類似度は長さを見ない。(1, 2) と (2, 4) は長さが違っても向きが同じなので 1 です。

ひとことで

大規模言語モデル(LLM)は、それまでのトークンから「次のトークンの確率」を計算し、1つ選んで後ろに足す、をくり返して文章を作ります。選び方は温度・top-k・top-p で調整します。

しくみ

LLM は文章をトークン(単語・単語の一部・文字などの小さな単位)に区切り、トークンの番号の列として扱います。どこで区切るかはモデルのトークナイザーで決まり、1文字が1トークンとも、1単語が1トークンとも限りません。

事前学習では、大量のテキストで「次のトークンは何か」を当てる次トークン予測をくり返します。正解は文章そのものの中にあるので、人がラベルをつけなくても学習できます。多くの LLM は Transformer を使い、予測のときに先のトークンを見ないようにして学習します。

文章を作るときは、予測した確率から次のトークンを1つ選んで入力の後ろに加え、それをもとにまた次を予測する、をくり返します(自己回帰生成)。10 トークン作るには、次トークン予測を 10 回行います。

  1. 入力「今日の天気は」→ 次のトークンの確率を計算 → 「晴れ」を選ぶ。
  2. 入力「今日の天気は晴れ」→ 次の確率を計算 → 「です」を選ぶ。
  3. 終わりを表すトークンが選ばれるか、長さの上限に達するまで続ける。

モデルは候補ごとのスコア(ロジット)を出し、ソフトマックスで確率にします。温度 T つきでは、ロジットを T で割ってから確率にします(T = 1 なら元のまま)。

候補 i の確率=exp(zi ÷ T)すべての候補の exp(z ÷ T) の和

exp(a) は ea(e ≒ 2.718 の a 乗)、zi は候補 i のロジット。

どの候補の確率も 0 より大きく、合計は 1 です。すべてのロジットに同じ数を足しても、分子も分母も同じ倍率になるので確率は変わりません。確率を決めるのはロジットどうしの差です。T を小さくするとロジットの差が広がり、最大の候補に確率が集中します。T を大きくすると差が縮まり、確率は均等に近づいて、出力が多様になります。

確率からの選び方にも種類があります。

  • 貪欲法: 毎回、最も確率の高いトークンを選ぶ。ランダムさがなく、同じ入力なら同じ出力になりやすい。温度を 0 に近づけたときの選び方に近い。
  • top-k: 確率の大きい上位 k 個だけを残し、合計が 1 になるように直してから選ぶ。
  • top-p: 確率の大きい順に足していき、累積が p 以上になるまでの候補を残して選ぶ。

事前学習のあと、目的に合ったデータで追加学習して調整するのがファインチューニングです。ゼロから学習するより少ないデータで、特定の目的や話し方に合わせられます。対話向けのモデルでは RLHF(人間のフィードバックによる強化学習)も使われます。人がどちらの応答がよいかを比べたデータで報酬モデルを学習し、その報酬が高くなるように、強化学習で言語モデルを調整します。

モデルが一度に扱えるトークン数の上限をコンテキスト長といいます。多くのモデルでは、入力と出力を合わせたトークン数がこの上限以内でなければなりません。なお、画像を作る生成AIでは、拡散モデルなど別のしくみもよく使われます。

例で確かめる

例1: ソフトマックスと温度(上の図)

ロジット (2, 1, 0)。e2 ≒ 7.389、e ≒ 2.718。

  1. T = 1: 和は 7.389 + 2.718 + 1 ≒ 11.107。晴れ = 7.389 ÷ 11.107 ≒ 0.67、曇り ≒ 0.24、雨 ≒ 0.09。
  2. T = 2: ロジットを 2 で割って (1, 0.5, 0)。e0.5 ≒ 1.649 なので、晴れ = 2.718 ÷ (2.718 + 1.649 + 1) ≒ 0.51。
  3. ロジット (3, 2, 1) は (2, 1, 0) に 1 を足しただけなので、確率は同じ 0.67、0.24、0.09。

例2: top-k と top-p

次のトークンの確率が「A 0.4、B 0.3、C 0.2、D 0.1」のとき。

  1. top-k(k = 3): A・B・C を残す。合計 0.9 で割り直すと A ≒ 0.444、B ≒ 0.333、C ≒ 0.222。
  2. top-p(p = 0.75): 大きい順の累積は 0.4 → 0.7 → 0.9。0.75 以上になるのは3つ目なので、残るのは 3つ(A・B・C)。

例3: コンテキスト長

上限 4096 トークン、入力 3000 トークンなら、出力に使えるのは最大 4096 − 3000 = 1096 トークン。

よくある誤解・注意

  • 文章全体を一度に決めているわけではない。1トークンずつ、前から順に選んでいます。
  • もっともらしい = 正しい、ではない。LLM は「ありそうな続き」を生成するので、事実と異なる内容や存在しない出典をもっともらしく作ることがあります(ハルシネーション)。重要な内容は出典で確かめます。信頼できる資料を検索して入力にふくめる RAG も、減らす工夫の1つです。
  • ロジットが負でも確率は 0 にならない。e の何乗かは必ず正なので、どの候補にも 0 より大きい確率が残ります。
  • 温度を上げるほど良い、ではない。多様にはなりますが、ありそうもない語も選ばれやすくなります。
